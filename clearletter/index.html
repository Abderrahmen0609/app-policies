ClearLetter Privacy Policy

Updated 16 October 2026. This page describes the local document-import update prepared for version 1.1.0. Until that update is available to your testing group, version 1.0.2 remains a sample-letter preview without actual OCR or PDF extraction.

What the local update does

On Android, you can select a JPEG or PNG image, take a photo using the system camera, or select an unencrypted PDF for on-device Latin text recognition. The app stops copying selected file-provider data before exceeding 20 MiB. The system camera first writes an app-owned capture file, which is size-checked after capture; this is not a pre-capture disk limit. Imports are limited to ten PDF pages, with additional image, page, text and processing-time limits. Arabic recognition is unavailable. Other platforms offer manual text entry. Review and correct text before saving it: recognition can be inaccurate or incomplete.

The update stores documents, personal notes, dates you enter and editable reply drafts. It does not provide automatic document interpretation, verified deadline detection, AI chat, legal advice, cloud accounts, synchronization, payments or scheduled notifications. Earlier preview records are labelled as examples, rather than treated as genuine scans.

Information kept on your device

Document titles, senders, categories, text, personal notes, manually entered dates and reply drafts are stored in app preferences without additional app-level encryption. App settings are also local. New documents and workspace growth are limited to 200 documents and 8 MiB of serialized text. Valid larger records from earlier versions remain readable and can be reduced or deleted.

The app processes selected images and PDFs locally. It does not upload document files, recognized text or notes to an AI or synchronization service. Selected originals are not changed or retained in the document vault. Import processing uses temporary files in the app's private cache, and clears its working files before reporting success. Interrupted processing can leave temporary files until the next import, Delete All Documents, Android cache removal or app-data removal. Files created or retained by the system camera, file picker or another application are separate from this cache.

Google recognition SDK and network information

The Android app bundles Google's ML Kit Latin recognition model. Its SDK initializes when the app starts, before an import is selected. It collects per-installation identifiers, device and app information, performance metrics, image-format/resolution configuration, input/output sizes, feature versions and initialization/detection/error events for diagnostics, usage analytics and detecting misuse or abuse. Document image and text recognition occurs on the device. SDK telemetry is sent to Google over HTTPS; it is not an optional app setting. Google states that it does not transfer the listed ML Kit telemetry to third parties. See Google's ML Kit disclosure, ML Kit privacy information and Google's privacy policy.

The app uses internet and network-state access for SDK network activity and user-initiated online actions. Camera and file selection use system interfaces. No location access is used. Fonts are bundled, and the app contains no advertising SDK. Opening this policy in a browser or contacting support uses your chosen browser or email service under its own policies.

Retention and deletion

The controls described below apply to version 1.1.0. In the older 1.0.2 sample preview, Delete All Documents is incomplete: use Android's Clear data control to erase that version's app records.

Current document records remain until you edit or delete them. Deleting one document removes its current linked notes, dates and reply draft together. Original preference records from an earlier version are preserved during migration, including records that cannot be read, to avoid silently destroying data. These retained originals are removed by Settings > Delete All Documents.

Delete All Documents removes the current document workspace, retained document migration originals and temporary files inside the new app-owned import cache. It keeps other app settings. Copies left by picker libraries in an older installation's cache are outside that control: use Android Settings > Apps > ClearLetter > Storage > Clear cache to remove those older working copies. If document erasure cannot be confirmed, the app reports the failure and blocks document use until you retry it; do not treat a failed attempt as complete erasure. Android's Clear data control removes local app preferences and cache as well. Android backup is disabled.

Local deletion does not delete selected source files, copies outside this app, files held by system picker/camera applications or Google SDK service logs. For questions about information handled by Google, consult its privacy controls and policy. For information you send directly to us, contact the address below.
