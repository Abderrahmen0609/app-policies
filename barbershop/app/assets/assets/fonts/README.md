# Offline QR poster fonts

These fonts are bundled so printable posters preserve customer-facing names
and addresses without downloading a font or sending poster text to a font
service at runtime.

- `Roboto-Regular.ttf` and `Roboto-Medium.ttf` are the Roboto assets vendored
  by the Flutter engine. See `LICENSE-APACHE-2.0.txt`.
- `NotoNaskhArabic-Regular.ttf` is the Noto Arabic fallback vendored by the
  Flutter engine. See `LICENSE-OFL-1.1.txt`.

The PDF generator embeds only the glyph data needed by the generated document.
